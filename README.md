# Учёт товаров

Это моя небольшая программа на C++. Она помогает вести список товаров.

В программе можно добавить название товара, его цену и количество. После ввода она показывает весь список, считает стоимость всех товаров и находит самый дорогой товар.

Также можно ввести название и проверить, есть ли такой товар в списке.

Я добавил проверки: цена должна быть больше нуля, а количество не может быть отрицательным.
